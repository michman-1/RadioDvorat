# RadioDvorat
Radio Dvorat is a project aiming to create and maintain an online radio broadcast service.
The radio is created on behalf of a bulgarian company [Dvorat EOOD](https://dvoratbg.com).
It is non-profit, does not contain any third-party ads, altho it is branded by Dvorat.

## Used Technologies
* **Server:** Ubuntu Server VM, Docker, Nginx
* **Streaming:** AzuraCast (Icecast/Liquidsoap)
* **CMS & Web:** WordPress, Elementor, Custom CSS/JS, AzuraCast REST API
* **Utilities:**  Google Remote Desktop

## 🛠️ Scope of my work
1. **Infrastructure and Server:**
* VM configuration and security (UFW firewall, Fail2ban).
* Implementation of AzuraCast in a container environment (Docker).

2. **Integration and Web Development:**
* Partially Building a website based on WordPress and Elementor.
* Integration between the website and AzuraCast API (custom radio player fetching stream metadata, a built-in song-request interface).

3. **Maintenance and Automation:**
* Monitoring service availability and resolving technical incidents.
